# Documentation

Reference documentation for how Aether Library works. Start with the
[README](../README.md) to install and run it; these pages explain the systems
behind what you see.

## Technical

- **[AI Council](technical/ai-council.md)** — how a discussion works: the
  Scholars, the Grand Sage, and the difference between Council and Mentor
  mode.
- **[Providers](technical/providers.md)** — the supported AI backends, how to
  configure them in AI Config, and where your API keys are stored.
- **[Vault](technical/vault.md)** — your local Markdown knowledge folder: how
  discussions are saved to it, and how your existing notes are used as
  context.
- **[Archives](technical/archives.md)** — the automatic local history of
  completed discussions, and how to reopen or continue one.
- **[Obsidian Integration](technical/obsidian-integration.md)** — the
  optional bridge to an existing Obsidian vault, and the rules that keep it
  from ever touching your existing notes.

# Tutorial preview images

Optional per-step images for the onboarding tutorial.

Only project-relative paths under this directory are accepted, and only
`.png`, `.jpg`, `.jpeg` and `.webp`. Remote URLs, `data:`/`file:` payloads,
absolute paths, `..` traversal and SVG are rejected server-side.

Images are optional: a step with no image, or one whose file is missing,
renders normally and never blocks tutorial navigation.

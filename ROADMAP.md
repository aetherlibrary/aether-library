# Roadmap

What has shipped, and the direction after it. See [README.md](README.md) for
what the product does today and [CHANGELOG.md](CHANGELOG.md) for
version-by-version detail.

Nothing below is a commitment or a schedule. Planned work is described
because it explains where the product is going, not because it is promised.

## Shipped

**v1.0.0 — Initial Public Release** *(current)*

The application foundation — settings architecture, localization, the native
Vault, optional Obsidian integration and Archives — together with the unified
conversation workspace: one composer, continuous follow-up conversation, a
collapsible discussion summary, follow-ups persisted to both the Vault and
Archives, a curated model catalogue, and end-to-end runtime reliability work
on timeouts and failed-model handling.

## Next

**Living Library**

Bringing the library itself to life: character animation, and a stronger
in-world presence for the Scholars and the Grand Sage during a discussion, so
that what the application is doing is visible in the room rather than only in
the workspace.

**Packaged desktop applications**

Installable Windows and macOS builds, so Aether Library can be launched like
any other application instead of run from source.

## Under consideration

Direction only. None of the following is designed or built.

- Additional Scenes beyond the Classic Library.
- Additional interface languages.
- Semantic retrieval for the Vault, once keyword search stops being enough.
- Additional Vault storage options beyond the local filesystem.
